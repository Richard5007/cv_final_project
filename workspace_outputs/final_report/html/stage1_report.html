1. 資料規範與實驗設計

Stage 1 的目標是從頭建立鋼材表面瑕疵分類的基準線，並驗證常見的訓練改善技巧是否真的有效。為了確保比較公平，本階段僅使用 Classification Public Dataset（Train = 1,260 張，每類 210 張；Validation = 270 張，每類 45 張），固定 seed = 42，也不使用任何預訓練權重或現成骨幹（如 ResNet、VGG、MobileNet）。所有影像統一轉為 200×200 單通道灰階，並以訓練集統計量 mean = [0.5071]、std = [0.2132] 做標準化。

2. Part A：Traditional Baselines（PCA + SVM / PCA + KNN）

在寫 CNN 之前，我們先用傳統機器學習方法當作基準。作法是將灰階影像縮成 64×64（4,096 維向量），只在訓練集上擬合 StandardScaler 與保留 95% 變異量的 PCA(n_components=0.95)（實際保留 33 維主成分，累積解釋變異量為 95.03%），接著分別訓練 RBF-SVM (C=10.0, gamma='scale') 與 KNN (k=5, distance weighting)。

3. Self-Designed Baseline CNN 架構與訓練設定

我們自己設計了一個四層的輕量卷積網路 SteelDefectCNN：包含 4 個卷積區塊（通道數 1 → 32 → 64 → 128 → 256，皆為 3×3 kernel、padding=1、Kaiming Normal 初始化與 ReLU），前 3 個區塊接 MaxPool2d(2×2)（解析度由 200 → 100 → 50 → 25），第 4 個區塊後接 AdaptiveAvgPool2d(1×1)，最後以 Linear(256→128) → ReLU → (可選 Dropout) → Linear(128→6) 輸出分類結果。

  • Baseline（E1）前處理：僅使用 Resize(200, 200) → ToTensor() → Normalize([0.5071], [0.2132])。
  • 固定訓練參數：Adam(lr=1e-3)、Batch Size = 32、Epochs = 80、CrossEntropyLoss、Seed = 42。

4. Part B：Improvement Methods 與消融實驗（Ablation Study）

為了看清楚每個改善方法的獨立效果，我們以 E1 為基準，依序測試以下三組設定（E1–E5）：

  • Method A（Batch Normalization）：在每個 Conv2d 後面加上 BatchNorm2d（同時關閉 conv bias），幫助深層特徵分佈穩定。
  • Method B（Data Augmentation）：訓練時加入隨機水平翻轉（p=0.5）、垂直翻轉（p=0.5）、旋轉（±15°）與亮度對比調整（ColorJitter(brightness=0.2, contrast=0.2)）。
  • Method C（Regularization + Early Stopping）：分類頭加入 Dropout(p=0.3)、優化器設定 weight_decay=1e-4，並以 Validation Macro F1 監控 Early Stopping(patience=20)。

Final Improved CNN 選擇理由（選定 E4）：
  • 為什麼在 Clean Val 都拿 1.0000 的情況下還要比較？ 一開始跑完 E1–E5 時我們有點意外，五組在 270 張潔淨驗證集上最佳檢查點都達到 1.0000。但如果只看最高 F1 其實分不出好壞，所以我們進一步檢查收斂速度、Validation Loss 與偏移泛化力： (1) 單加 BatchNorm（E2） 讓最佳 Val Loss 從 E1 的 0.02629 降到 0.00493，且第 19 epoch 就突破 0.98 F1（E1 要到第 24 epoch）； (2) 單加 Data Augmentation（E3） 把 Val Loss 降到 0.00348，同時在輕微旋轉／亮度偏移診斷（Mild-Shift Probe）中把 F1 從無增強組的 0.2907（E1）與 0.5573（E2）拉高到 0.9852。
  • 最終選擇 E4（A + B 結合）：E4 在第 14 epoch 就達到 0.98 F1（五組最快），最後 10 個 epoch 的平均 Val F1 最高（0.9915）、平均 Val Loss 最低（0.0229），而且在偏移測試上拿到滿分 1.0000。比較之下，E5 在僅 42 萬參數的小模型上同時疊加 Dropout(0.3) 與 L2(1e-4) 並在第 66 epoch 提早停止，反而略微欠擬合（Val Loss = 0.01364）。
  • 模型大小與參數量：E4 僅 421,990 參數（1.62 MB），在輕量架構下兼顧高準確率與穩定泛化表現。
