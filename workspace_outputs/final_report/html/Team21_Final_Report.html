1. Problem & Dataset（問題背景與資料集特性）

本專題模擬智慧製造鋼材產線的表面瑕疵檢測問題，系統除了要分辨六類瑕疵（crazing 龜裂、inclusion 夾雜、patches 斑塊、pitted_surface 點蝕、rolled_in_scale 氧化鐵皮壓入、scratches 刮痕），還需進一步標出瑕疵座標，並考量實際工廠的光照變化、模糊、壓縮雜訊與運算成本。

  • 資料切分與規範：課程提供 FactoryVision_STUDENT_PUBLIC，Classification 與 Detection 共用相同的 Master Split：Train = 1,260（每類 210 張）、Validation = 270（每類 45 張）。所有實驗固定 seed = 42，禁用外部微調權重，Validation 僅用來挑模型與調參。
  • 三階段分工：Stage 1 先用傳統特徵與自己刻的 CNN 驗證基本方法；Stage 2 系統性比較兩種預訓練骨幹在不同微調策略下的抗干擾表現；Stage 3 則進入 Bounding-Box 偵測，比較單階段與雙階段模型的定位準度與模型複雜度。
  • 我們觀察到的資料特性（200×200 影像）：統計標註檔後發現六類瑕疵大小落差很大——inclusion 中位寬只有 23 px、scratches 細長、pitted_surface 與 crazing 則常佔滿整張圖；另外全資料集中共有 104 張圖同時存在一種以上的瑕疵，這也是為什麼最後實務上必須走向 Object Detection。

2. Stage 1：Baseline 與 Improved CNN

先看傳統方法：將灰階圖縮成 64×64 做標準化與 PCA(0.95)（保留 33 維主成分，解釋 95.03% 變異）後，PCA + KNN 只拿到 Val Macro F1 = 0.6302，PCA + SVM (RBF) 提升到 0.7546 但對細長紋理仍常誤判。接著我們自己設計四層卷積的 SteelDefectCNN（421,990 參數，從頭訓練 80 epochs），做 E1–E5 消融實驗。有趣的是 E1–E5 在潔淨驗證集最後都達到 1.0000，因此我們另外做了 ±15°／±20% 亮度對比的偏移診斷（Mild-Shift Probe），才明顯看出 E4 (BN + DataAug) 的抗偏移能力最好（1.0000 vs. E1 0.2907）：

5. Failure Analysis（跨 Stage 主要錯誤案例與根本成因）

  • 1. 跨類別紋理混淆與資料增強消融診斷（Stage 1）：PCA + SVM 在細長或點狀紋理上嚴重失誤，inclusion（F1 = 0.58）與 scratches（F1 = 0.66）常相互混淆；自建 CNN 雖在潔淨驗證集達 1.0000，但在 ±15° / ±20% 亮度對比偏移診斷中，無增強基準 E1 急劇崩跌至 0.2907、僅加 BN 之 E2 僅 0.5573，直到結合 BN 與資料增強（E4）才維持 1.0000 抗偏移穩定度。
  • 2. 光照與壓縮雜訊對 Frozen Feature Extraction 的衝擊（Stage 2）：僅訓練分類頭時，預訓練淺層濾波器對鋼材高頻壓縮失真脆弱，DenseNet121 FE (E1) 於 Sensor/JPEG 跌至 0.8158（Overall Robust = 0.8855）；經統一 Robustness-Aware 增強與全層微調後，E6 (MobileNetV3-Large Full FT) 達成 Clean 1.0000 與 Local Robust 0.9938（全測試 810 張僅 5 筆誤判）。
  • 3. 空間定位難類、小目標漏檢與多標籤結構瓶頸（Stage 3）：即便最強檢測器 Faster R-CNN R50-FPN-v2，於瀰漫低對比之 crazing（AP = 0.5093）與 rolled_in_scale（AP = 0.6692）仍常見 Poor Localization（IoU < 0.5），微小型 inclusion（中位寬 23 px）偶發 FN；此外資料集共含 104 張複合瑕疵影像，Stage 1–2 單標籤模型結構上無法輸出第二類別，唯有 Stage 3 檢測器能精準解析複合瑕疵空間分布。

7. Conclusion（最終 FactoryVision 系統部署建議）

最終系統決策：依照產線工位需求採用「YOLO11m（輕量定位主線）＋ Faster R-CNN R50-FPN-v2（高精複檢站）＋ MobileNetV3-Large E6（惡劣成像備援）」
  1. 高精確度定位主模型：若目標是最大化偵測準確度與召回率（例如品管站或離線複檢），我會選擇 Stage 3 Faster R-CNN ResNet50-FPN-v2（驗證集 mAP@0.5 = 0.7866，檔案 165.5 MB），它在難檢的 crazing 與 rolled_in_scale 上表現明顯優於單階段模型，也能處理複合瑕疵影像。
  2. 輕量多目標定位工位：若產線邊緣設備受限於模型容量與記憶體，實務上可採用同實驗證過的 YOLO11m（mAP@0.5 = 0.7603、檔案僅 38.7 MB）做第一線定位篩檢，有疑似框再送交 Faster R-CNN 複核。
  3. 強干擾環境與低資源分類備援：當鏡頭油霧／強光閃爍嚴重或僅需整張圖分類把關時，改以 Stage 2 E6（MobileNetV3-Large Full Fine-tuning）（僅 16.24 MB、Local Robust Macro F1 = 0.9938）作為備援；產線告警門檻建議設於 conf = 0.25–0.30，兼顧低誤報與高召回。
